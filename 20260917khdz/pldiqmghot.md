# 左眼跳财，右眼跳灾？眼皮跳可能是面神经出问题了！

> 更新时间：2026-09-17 (UTC+8)

白领张小姐，平时工作繁忙，经常加班，昨晚自觉身体疲倦且右眼皮间歇跳动。早上起来，她照镜子发现右眼无法闭上，嘴巴向右歪斜，吃早餐时食物停在一边转不过来，张小姐担心会不会脑中风了，随即到中山一院急诊就诊，经神经内科及耳鼻咽喉科会诊并进行相关检查后，她被诊断为面瘫及特发性面神经炎，经激素等药物及针灸治疗，右眼皮跳动及面瘫恢复。

无独有偶，同一时期耳鼻咽喉科另一患者洪先生，因同一类疾患就诊。洪先生经营一家公司，生意一直很火红。1年来，他间歇出现左眼皮跳动，应酬喝酒后更容易出现，休息后可自行消失，他迷信民间传说的“左眼跳财，右眼跳灾”，一直未就医。近2周，他的左眼跳动加重伴面部麻木、左眼闭合困难，就诊后进行CT检查提示左耳颞骨内面神经肿瘤，被诊断为面瘫及面神经瘤，经手术后，他的面神经功能部分恢复。以上2例是面神经功能受损导致眼皮跳动及面瘫的典型病例。

面部肌肉除了能让我们拥有丰富的表情外，还具备一些重要功能比如说鼓腮，漱口时的含水动作及吹口哨之类动作。面肌灵活运动离不开一个结构和功能都正常的面神经。
面部肌肉运动及感觉是由面神经支配（图1），当面神经受到各种病理因素刺激出现病变，轻则眼皮跳动，严重者表现面瘫。面瘫是耳鼻咽喉科临床常见病、多发病，年发病率约 0.2%～1%，发病呈逐年递增趋势，年龄及性别无明显差异，单侧为主。面瘫处理不及时或延误治疗将可造成严重并发症，难以逆转，严重影响患者容貌及心理健康。 ▲图1 左面部面神经分支

**面瘫常见症状**

1.眼皮跳动、口角歪斜或闭眼障碍，炎性面神经疾病通常一侧发病，进展较快。面神经肿瘤所致症状则呈缓慢逐渐加重过程。
2.不自主流泪或者无泪、角膜干燥，与面神经疾病受累的部位有关。
3.味觉异常，侧舌部味觉异常如出现甜味、辛味或味觉消失。
4.听觉过敏，对强声难以忍受，易头晕。

**面瘫如何分类**

日常生活如果出现面瘫，首先可在家自测面瘫的类型，面瘫分为中枢性面瘫、周围性面瘫。中枢性面瘫通常只有口角歪斜，颜面上部肌肉活动正常，闭眼、扬眉、皱眉均正常，大多与脑血管意外如出血、梗塞或脑肿瘤有关，这种情况需首诊于神经内科。
周围性面瘫引起患侧颜面部肌肉瘫痪，眼睑不能闭合，额纹变浅或者消失，口角向健侧歪斜，需要到耳鼻咽喉科就诊。 

**面瘫常见病因**

**中枢性面瘫：**多由脑血管意外、脑肿瘤和脑炎等中枢系统病变所致。
**周围性面瘫：**多见于感染、肿瘤或创伤等，其中贝尔面瘫是最常见类型，约占周围性面瘫的61%～76%；其次是耳带状疱疹，发病率约11.5%；外伤性周围性面瘫，发病率约8.1%；炎症感染引起面瘫，包括中耳炎症、腮腺炎等，以胆脂瘤型中耳炎多见，发病率0.16%～5.1%；其他如肿瘤性面瘫, 包括面神经瘤、中耳癌、听神经瘤等。

**面瘫能否自愈**

一般来说，面瘫无法自愈，均需积极治疗。根据不同病因，面瘫治愈率不同。例如临床上常见的贝尔面瘫，治愈率相对高，大部分患者3周左右恢复,其余约15%患者3～5个月内恢复；年轻患者，面神经损伤较轻，可以完全自愈。年龄偏大患者，合并基础病如糖尿病、高血压等，治愈率偏低，可出现不同程度面瘫后遗症。

**面瘫如何治疗**

面瘫处理原则是早诊断、早治疗。中枢性和周围性面瘫的处理方案不一样。中枢性面瘫首先要明确病因及对因治疗。周围性面瘫，根据不同病因，可采用如下方案。
1. 常见的贝尔面瘫、耳带状疱疹、创伤及炎症所致面瘫。早期治疗以药物为主，如激素、抗病毒治疗、神经营养及改善循环治疗。 
2. 康复治疗。一般认为，急性期（7天内）是康复及针灸等治疗的禁忌期，针对恢复期（8天～2个月）以后的康复综合治疗包括按摩、针灸等，对面神经功能恢复具有肯定疗效。
3. 面神经减压术。适用于经药物保守治疗无效的患者，面神经电图提示面神经变性超过90%，病程2～4周内，面神经减压效果较好。
4. 面神经吻合术及移植术。适用于病程超过2年、面神经断裂以及肿瘤性面瘫病例。

**面瘫后遗症**

面瘫病程超过3个月，后遗症常见分为两类：**
****1. 迟缓性面瘫后遗症：**口角歪斜及闭眼障碍，进食时伴随流泪现象，俗称鳄鱼泪。
**2. 痉挛性面瘫后遗症：**出现了和原本发病症状相反的后遗症，例如原来眼睛闭不上，后来出现睁眼困难；发病时原来口角歪向健侧，后来口角歪向患侧。面瘫后联动，眼睑动嘴角也动，原因是面神经损伤后神经纤维再生出现错位生长。面肌痉挛，面部肌肉出现阵发性的不自主抽搐，疲劳、精神紧张可加重发作，不受意识控制。

**面瘫后遗症的治疗**

面瘫后遗症主要是以康复治疗（针灸、理疗按摩，康复运动等）为主，适当应用神经营养药物。对于面肌痉挛，可定期门诊局部注射肉毒毒素缓解面肌痉挛症状。对于面瘫病程超过2年以及面神经中断（外伤或肿瘤所致）病例，可选择面神经吻合术及移植术或咬肌肌蒂转移术等，具有一定疗效。

**面瘫康复期的自我护理**

1. 面部肌肉活动障碍，可通过康复手法，活动面部及眼周肌肉，减缓肌肉萎缩。
2. 面瘫患者出现眼睑闭合不全，角膜长时间暴露容易引起角膜炎，日常生活要注意保护眼睑及角膜，如睡前涂抹眼膏及消毒纱布外盖。
3. 注意防寒保暖，避免用冷水拍打面部，睡眠时避免凉风长时间刺激脸面部。
