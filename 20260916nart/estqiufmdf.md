# “小石头”引发大危机！8岁娃肠子被堵死，微创手术紧急取出4厘米巨型粪石

> 更新时间：2026-09-16 (UTC+8)

近日，东营市人民医院（山东省立医院集团东营医院）儿外科成功救治一名因粪石堵塞导致完全性肠梗阻的8岁患儿。从剧烈腹痛、呕吐不止，到微创手术化险为夷，这场与时间的赛跑，再次为儿童饮食安全敲响警钟。

**多学科联动锁定“元凶”**

**粪石从何而来？**

**这些饮食习惯是“帮凶”**

粪石从何而来？所谓“粪石”，并非普通的粪便，它是由未能消化的食物残渣、纤维，甚至毛发等，在肠道内与矿物质（如钙盐）结合，日积月累形成的坚硬团块。患儿的这枚粪石，经询问病史，与不当的饮食习惯有关：

1. **高纤维、高鞣酸食物过量摄入：**例如空腹一次性食用大量柿子、黑枣、山楂等。这些食物富含鞣酸和果胶，在胃酸作用下易凝结成块，形成“胃石”，进入小肠后可能继续包裹食物残渣变大变硬，形成粪石。

2. **饮食习惯不佳：**进餐不规律、暴饮暴食，或边吃饭边大量饮用碳酸饮料，可能影响消化功能，增加食物团块形成的风险。

3. **特殊体质因素：**部分孩子消化功能较弱，或肠道蠕动相对缓慢，也更容易形成粪石。

**预防胜于治疗**

**守护肠道从日常做起**

守护孩子肠道健康。小儿粪石性肠梗阻起病隐匿，但一旦发生梗阻，病情进展快，危害大。预防是关键，家长需注意以下几点：

1. **科学安排饮食：**避免让孩子空腹或一次性大量食用柿子、黑枣、山楂等易形成结石的水果。食用时最好在饭后，并适量。

2. **培养良好习惯：**鼓励孩子细嚼慢咽，规律三餐，避免暴饮暴食。餐后不宜立即进行剧烈运动，也不宜马上平躺。

3. **充足饮水与均衡膳食：**保证每日足量饮水，多吃富含水分的蔬菜水果（注意选择种类），保持膳食均衡，促进肠道正常蠕动。

4. **警惕异常信号：**当孩子出现阵发性或持续加重的腹痛、腹胀、呕吐、停止排气排便等情况时，切勿当作普通肠胃炎自行处理，应第一时间带孩子就医，并详细告知医生孩子的饮食史，以便早期诊断和干预。
